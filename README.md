# UNO Arena Online (2–6 players)

เกม UNO แบบเล่นหลายคนผ่านเว็บด้วย Node.js + Socket.IO

## วิธีรัน
1. ติดตั้ง Node.js 18+
2. เปิด Terminal ในโฟลเดอร์นี้
3. รัน:
   npm install
   npm start
4. เปิด http://localhost:3000

## ให้เพื่อนเข้าจากอินเทอร์เน็ต
นำโปรเจกต์นี้ไป deploy บนบริการ Node.js ที่รองรับ WebSocket เช่น Render/Railway/Fly.io แล้วส่ง URL ให้เพื่อน

## ฟีเจอร์
- ห้องส่วนตัวด้วยรหัส 5 ตัว
- รองรับ 2–6 คน
- เห็นรายชื่อเพื่อนและจำนวนการ์ดแบบเรียลไทม์
- Reverse, Skip, +2, Wild, Wild +4
- สลับมือกับผู้เล่นอื่น
- ระบบทิศทางเดินเกม
- แจกไพ่ 7 ใบ
- UI การ์ดแนว UNO
